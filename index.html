Mik Mak Muk

Bare-metal host automation, low-level kernel tuning, and USB networking for a 3-node mini PC cluster running CachyOS.

Repository (main) elastic-direct Branch

Project Overview

Mik Mak Muk provides baseline Ansible automation for a 3-node HP EliteDesk and ProDesk Mini cluster[cite: 1]. It manages hardware optimization, GPU video acceleration, and NVMe power states at the host operating system level prior to workload deployment[cite: 1].

Repository Branches

main

Handles the core base OS setup, kernel-level optimizations (`mitigations=off`, `i915` GPU configuration, NVMe latency parameters), and configures the dedicated USB-C cluster networking (VLAN 107)[cite: 1, 11].

elastic-direct

Extends the baseline setup to deploy and configure a bare-metal Elasticsearch & Kibana cluster running directly across the host nodes over the isolated USB cluster transport network[cite: 4, 8, 11].

Key Features

  • Declarative Automation: Agentless configuration using Ansible[cite: 1].
  • CachyOS Base: Custom kernel parameter tuning (`mitigations=off`, `i915` GPU configuration, NVMe power state latency)[cite: 1].
  • USB Networking: Isolated 2.5 GbE inter-node cluster network configured via NetworkManager without default gateway conflicts[cite: 11].
  • ADR Tracked: Architectural choices recorded directly via Architecture Decision Records[cite: 1].
